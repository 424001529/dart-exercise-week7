Scenario Description:
This program calculates the total bill for a store purchase, checks for applicable discounts, and evaluates member status.

Code Explanation:
The program processes a simple store purchase using core Dart constructs:
1. Variables: Stores the item name (`String`), quantity (`int`), price (`double`), and member status (`bool`).
2. Math: Multiplies quantity by price (`*`) to calculate the total bill.
3. Comparison: Checks if the total is high enough (`>=`) to get a discount.
4. Display: Prints the final details using `print()` with `$variables`.
